# Kuryana v2 API

Same MyDramaList data as v1, in a cleaner, consistent format.

| Endpoint | Description |
| --- | --- |
| `GET /v2/search?q={query}&page=1` | Search dramas and people |
| `GET /v2/dramas/{slug}` | Drama info |
| `GET /v2/dramas/{slug}/cast` | Full cast and crew, grouped by role |
| `GET /v2/dramas/{slug}/episodes` | Episodes |
| `GET /v2/dramas/{slug}/reviews?page=1` | Reviews |
| `GET /v2/people/{slug}` | Person info and works |
| `GET /v2/lists/{id}?page=1` | A user list |
| `GET /v2/users/{username}/dramalist` | A user's drama list |

`page` is optional and defaults to `1`.

## Response format

Every successful response looks like this. `data` holds only the scraped info.

```js
// GET /v2/people/4444-kim-jong-min
{
  "success": true,
  "data": {
    "name": "Kim Jong Min",
    "nationality": "South Korean",
    "age": 47,
    // ...
  },
  "link": "https://mydramalist.com/people/4444-kim-jong-min",
  "scraped_at": "2026-10-31T08:00:00Z"
}
```

Errors set the real HTTP status (`404`, `422`, `502`, ...) and return:

```js
{
  "success": false,
  "data": null,
  "message": "The requested page was not found. You can see this page because the URL you are accessing cannot be found."
}
```

## Changes from v1

- Numbers are numbers: `rating`, `year`, `episodes`, `ranked`, `watchers`, etc. are numbers or `null`, not strings like `""`, `"N/A"` or `"8.9/10 from 279 users"`.
- Slugs have no leading slash and work as-is in other v2 routes, e.g. a cast member's `slug` goes straight into `/v2/people/{slug}`.
- Search, reviews and lists return a `pagination` object (`page`, `total_pages`). v1 only returns the first page.
- Genres, tags, also-known-as titles and networks are arrays.
- Cast entries include `character` and `role`. Reviews include `id`, `date`, `headline`, `spoiler` and per-category `ratings`.
- Fixed v1 bugs: wrong poster on cast and review pages, `title` repeating the year, and news articles appearing in search results.
- An unknown drama returns `404` instead of `500`.

The v1 endpoints are still available. See [v1.md](v1.md).
