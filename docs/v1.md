# Kuryana v1 API (legacy)

The original endpoints are still available for use and won't change, so existing projects keep working.

- Search for dramas

```sh
GET /search/q/{yourquery}
```

- Get DRAMA Info

```sh
GET /id/{mydramalist-slug}
```

- Get DRAMA Cast

```sh
GET /id/{mydramalist-slug}/cast
```

- Get DRAMA Episodes

```sh
GET /id/{mydramalist-slug}/episodes
```

- Get DRAMA Reviews

```sh
GET /id/{mydramalist-slug}/reviews
```

- Get Person(People) Info

```sh
GET /people/{people-id}
```

- Get seasonal drama

```sh
GET /seasonal/{year}/{quarter}
```

`quarter` is 1–4 (Jan–Mar = 1). Any other value returns 422.

- Get episode schedule (the next 7 days)

```sh
GET /schedule
```

> [!NOTE]
> MyDramaList removed the JSON calendar APIs, so both endpoints now scrape the `/episode-calendar` pages. The response shape is not the same as the old passthrough. Times are the strings MDL shows. `timezone` is the title's source timezone.

```js
// GET /seasonal/2026/4 -> a list of titles. category is "Drama", "Movie" or "TV Show".
[{ "id": 731727, "title": "Your Personal Taxi", "url": "/731727-personal-taxi",
   "cover": "https://i.mydramalist.com/zBZqwy_4c.jpg", "category": "Drama",
   "type": "Korean Drama", "released": "October 1, 2026", "rating": 7.3,
   "ranked": 8970, "popularity": 8171, "synopsis": "...", "genres": ["Music", "Life"] }]

// GET /schedule -> one entry per day
[{ "date": "October 30, 2026", "weekday": "Friday", "items": [
   { "id": 781670, "title": "The Legacy", "url": "/781670-the-legacy/episode/9",
     "cover": "https://i.mydramalist.com/Ar3L03_4t.jpg", "time": "11:00 AM",
     "timezone": "Asia/Bangkok", "info": "Episode 9 - 10",
     "episodes": [{ "title": "Episode 9", "url": "/781670-the-legacy/episode/9",
                    "time": "11:00 AM", "date": "October 30, 2026 10:00 AM" }] }] }]
```

- Get Lists

```sh
GET /list/{id}
```

- Get User Dramalist

```sh
GET /dramalist/{user_id}
```

## Error Messages

```js
// mainly on all endpoints except `search`
// sample: /list/unknown-random-id
{
  "code": 400,
  "error": true,
  "description": {
    "title": "This list is private.",
    "info": "You can see this page because the URL you are accessing cannot be found."
  }
}
```

```js
  "error": true,
  "code": 404,
  "description": "404 Not Found"
}
```

## API Wrappers

A JS/TS and Python api wrappers are currently available. [Learn More...](https://gitea.com/tbdsux/kuryana-api-wrappers)

### JS/TS

```ts
import { Kuryana } from "@tbdhdev/kuryana-ts";

async function main() {
  const kuryana = new Kuryana();
  // const kuryana = new Kuryana("https://custom-endpoint.net");

  const res = await kuryana.search("goblin");

  if (!res.success) {
    console.error("Search failed:", res.error);
    return;
  }

  // log results
  for (const item of res.result.results.dramas) {
    console.log("Drama:", item.title);
    console.log("Year:", item.year);
    console.log("-----\n");
  }
}

main();
```

### Python

```python
from kuryana import Kuryana

client = Kuryana()


if __name__ == "__main__":
    response = client.get()
    print(response.message)

    assert "MDL Scraper API" in response.message

    print("\n\n")

    search = client.search("goblin")
    for drama in search.results.dramas:
        print(f"{drama.title} - {drama.year}")

```
